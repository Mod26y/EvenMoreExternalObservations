Original Article: https://www.bleepingcomputer.com/news/security/hackers-exploit-sangoma-switchvox-flaw-to-deploy-reverse-shells/

1) The article reports hackers exploiting a critical security vulnerability in the Sangoma Switchvox VoIP platform, labeled CVE-2026-9586. This issue involves an unauthenticated SQL injection at the /pa HTTP endpoint, allowing attackers to execute remote commands via crafted XML requests. The flaw is being used to deploy reverse shells, enabling malicious control over the systems. The exploitation has been detected in real-time, with attackers collecting system data and sending it to a remote server. The vulnerability was addressed with the release of Switchvox version 8.4.0.2 on July 14 following its discovery.

2) The matter is significant as Sangoma Switchvox is a widely used enterprise VoIP management system, meaning the exposure could impact numerous organizations, particularly in the United States where most systems are located. The vulnerability facilitates not only unauthorized access but also potential system control, making it an attractive target for cybercriminals. Such active exploitation poses a severe risk to network integrity, privacy, and business operations, potentially leading to substantial data breaches and operational disruptions.

3) Organizations using Switchvox should prioritize upgrading to version 8.4.0.2 or later to close the security gap. It is prudent to inspect server logs, particularly for unusual entries in /var/log/switchvox/db-quirks.log, and monitor network traffic for connections to the attacker's IP, focusing on port 39323. Implementing enhanced monitoring of system activities can detect further exploitation attempts, while educating staff on signs of suspicious behavior can help in early threat detection and response. Regular vulnerability assessments, alongside patch management practices, are recommended to maintain robust security postures against future vulnerabilities.
