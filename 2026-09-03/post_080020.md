Original Article: https://www.bleepingcomputer.com/news/security/wordpress-backup-plugin-flaw-exposes-millions-of-sites-to-takeover-attacks/

1. **What Happened:**
A critical SQL injection vulnerability, identified as CVE-2026-19949, was discovered in the popular All-in-One WP Migration and Backup plugin for WordPress. This flaw allows unauthorized attackers to perform remote code execution and potentially take over affected websites. The vulnerability, present in plugin versions up to 7.109, involves improper parsing of database content during archive restoration. Despite a patch being released on August 20, 2023, a significant portion of users have not updated, leaving millions of websites exposed to risk.

2. **Why It Matters:**
This vulnerability has far-reaching implications due to the plugin’s widespread use—over five million active installations. A successful exploit can lead to complete website takeover, resulting in potential data breaches, unauthorized data alteration, and service disruption. The vulnerability is particularly concerning given its activation relies on routine administrative actions. As a critical component in website operations, the potential for exploitation during ordinary backup and restore functions raises significant cybersecurity threats for businesses and individuals using the plugin.

3. **What Actions Should Be Taken:**
Administrators using All-in-One WP Migration and Backup should promptly update to the latest version (7.110 or higher) to mitigate this vulnerability. Regular plugin and theme updates should be a part of routine security practices. Administrators should review security logs for any suspicious activities, especially related to backup operations. Organizations may also consider implementing additional security plugins that monitor and block unauthorized SQL injection attempts while educating website administrators about secure plugin usage and regular maintenance checks to prevent similar vulnerabilities in the future.
