Original Article: https://www.bleepingcomputer.com/news/security/hackers-target-us-firms-in-fastjson-rce-zero-day-attacks/

A vulnerability in the FastJson Java library, with versions 1.2.68 through 1.2.83 affected, is being exploited by hackers allowing for remote code execution without user interaction. These attacks primarily target US-based organizations across diverse industries, including financial services, healthcare, and retail. Initially discovered by FearsOff and observed by ThreatBook, this flaw results from type-resolution logic issues that attackers can exploit to run malicious code in Spring Boot fat-JAR deployments.

This issue is crucial because it affects a widely used library, making numerous systems potentially vulnerable. FastJson is particularly popular in Chinese enterprise software and among projects leveraging Alibaba's platform. With no fix available and the FastJson 1.x version no longer maintained, there's a heightened risk for organizations using affected versions, leaving critical systems open to exploitation until mitigations are in place.

Organizations using FastJson within the affected versions should immediately consider enabling SafeMode or migrating to the unimpacted FastJson2 model. Disabling AutoType or switching to secure deployment models like non-fat-JAR can mitigate risks. Security teams should increase monitoring, test SIEM and EDR rules using strategies like breach and attack simulations to detect and prevent successful exploitations, and assess all deployments for potential exposure to the vulnerability.
