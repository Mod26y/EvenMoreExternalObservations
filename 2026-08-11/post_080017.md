Original Article: https://www.bleepingcomputer.com/news/security/bdthemes-plugins-supply-chain-hack-creates-rogue-wordpress-admins/

The BdThemes supply-chain hack involved a threat actor who compromised the infrastructure of BdThemes, a WordPress plugin developer, and manipulated a JSON feed to create rogue administrator accounts on affected websites. This attack leveraged a cross-site scripting (XSS) vulnerability in the JSON response parsing, allowing the injection of malicious code which exploited authenticated sessions of website administrators. As a result, the compromised plugins were temporarily unavailable to prevent further exploitation while thorough reviews and investigations took place.

This incident underscores the vulnerabilities present in supply chains and third-party components. It highlights how malicious actors can exploit coding flaws to gain unauthorized access and control within widely-used applications, such as WordPress. Given BdThemes' plugins are used across hundreds of thousands of websites, this event emphasizes the importance of securing supply chains to prevent widespread security breaches that could compromise sensitive data or system integrity at scale.

In response to this situation, organizations using BdThemes products should review their current security posture and actively search for rogue admin accounts to mitigate ongoing risks. It's prudent to monitor communications from BdThemes and WordPress for updates on patches or further actions. Furthermore, deploying web application firewalls and continuously reviewing supply chain security can help detect and respond to anomalies swiftly, reducing potential exposure to similar incidents.
