Original Article: https://www.bleepingcomputer.com/news/security/plug-and-pwn-attack-uses-fake-usb-devices-for-windows-system-access/

**1) What happened?**

Security researchers unveiled a new attack method dubbed "Plug and Pwn," which manipulates Windows' Plug and Play functionality to gain SYSTEM privileges by tricking Windows into installing insecure vendor software. By emulating USB devices using a Linux toolset with FaceDancer, attackers can create conditions for Windows to install exploitative packages. The attack method was demonstrated at DEF CON 34, showing that it requires no user interaction and can even be executed remotely via RDP by crafting specific USB device descriptors, thus potentially executing malicious code with SYSTEM-level privileges.

**2) Why it matters?**

The Plug and Pwn attack indicates a significant vulnerability in Windows' device installation process that could be exploited to gain unauthorized access to critical system privileges. Given its ability to operate remotely with minimal user interaction, this method presents a severe risk for IT environments, especially those incorporating virtual desktop infrastructures or RDP. This highlights the critical importance of securing device installation processes and being vigilant about automated hardware and software interactions, reminding organizations of the need to bolster their defenses against evolving hardware emulation and installation path exploits.

**3) What actions should be taken as a result of this information?**

Organizations should consider modifying Windows settings to mitigate Plug and Pwn risks. Disabling co-installers by setting the 'DisableCoInstallers' registry value can prevent certain exploit chains, although it won't eliminate all risks. Implementing device installation restrictions or employing hardware-ID allow-lists may further secure systems. Additionally, turning off Plug and Play device redirection on RDP and VDI hosts where it is unnecessary can address remote exploitation concerns. IT security teams should also stay informed about vulnerabilities and apply necessary patches and workarounds to minimize exposure to such attacks.
