Original Article: https://www.bleepingcomputer.com/news/microsoft/windows-server-2022-reaches-end-of-mainstream-support-in-60-days/

1) **What happened:** Microsoft announced that Windows Server 2022 is nearing the end of its mainstream support phase, which will conclude after the security update on October 13, 2026. After this date, it will transition to extended support, which includes security updates until October 14, 2031. Microsoft recommends IT administrators start planning upgrades to Windows Server 2025, which offers full mainstream support until November 13, 2029, with additional extended support into 2034. The company has also extended certain other support features, like hotpatching for Datacenter: Azure Edition, beyond the mainstream end date.

2) **Why it matters:** End of mainstream support means that although security updates will continue, there will be no more feature updates or non-security bug fixes, potentially leaving systems vulnerable as threats evolve. Organizations relying on Windows Server 2022 need to plan upgrades to newer versions to maintain support, functionality, and optimal security posture. Extended support focuses solely on critical vulnerabilities, so staying on outdated systems may expose organizations to other risks. The end of mainstream support also signals potential challenges for compliance and compatibility as software ecosystems advance.

3) **What actions should be taken:** Organizations should inventory their current infrastructure to identify any systems running Windows Server 2022. IT departments are encouraged to assess and plan their transition to Windows Server 2025, conducting a full evaluation and testing in secure environments using the available 180-day trial. It's also vital to update internal policies to ensure ongoing monitoring of end-of-support timelines to avoid future interruptions. Communication with users about upcoming changes and their implications can ease the transition. Consider leveraging guidance from Microsoft and third-party IT solutions to strategize and implement a successful upgrade path.
