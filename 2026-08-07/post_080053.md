Original Article: https://www.bleepingcomputer.com/news/security/new-tontou-cpu-attack-bypasses-spectre-v2-fixes-leaks-linux-password-hashes/

1) The incident involves a new technique called TONTOU (Time-of-Neutralization to Time-of-Use) that circumvents previous Spectre v2 speculative execution mitigations on Linux systems running on AMD and Intel CPUs. Researchers developed an Interrupt Injection attack allowing unprivileged user programs to schedule timer interrupts during kernel execution. This exploit can redirect and poison the CPU’s indirect branch predictors, leaking sensitive data such as Linux password hashes with reasonable speed and accuracy. The attack was demonstrated successfully on AMD Zen 2 systems and is possible, albeit complex, on Intel processors.

2) This development matters as it exposes a critical vulnerability in the mitigation strategies for speculative execution attacks, potentially undermining the security of all affected systems globally. With the ability to leak sensitive information like password hashes, this exploit could be used to escalate privileges and compromise systems. It highlights the ongoing arms race between attackers and defenders, emphasizing the need for robust, adaptive, and layered defenses in modern CPU architectures to mitigate such evolving threats.

3) Organizations, especially those relying on Linux systems, should stay informed about forthcoming patches and updates from CPU vendors and the open-source community to address this new attack vector. Security teams should review and potentially enhance current detection strategies in their SIEM and EDR solutions to identify unusual interrupt patterns. Consider engaging with breach and attack simulation services to identify any gaps in security posture and improve incident response capabilities. Increasing awareness and vigilance can help mitigate potential exploitation until permanent fixes are in place.
