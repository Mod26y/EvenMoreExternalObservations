Original Article: https://www.bleepingcomputer.com/news/security/hackers-run-khunt-post-exploitation-toolkit-from-oracle-database/

In this incident, hackers exploited a SQL injection vulnerability in an Oracle database via a vulnerable Java application to install a post-exploitation toolkit called khunt. This toolkit was embedded within the database, leveraging Oracle's functionality to compile and execute Java code. The attackers used various components of khunt to execute system commands, access credential data, and manage files on the host server. They achieved SYSTEM-level permissions and attempted credential dumping using registry hives. This complex attack underscores the potential for significant breaches through overlooked application vulnerabilities.

The vulnerability's exploitation poses serious security concerns. It underscores the need to protect database and application integration points, particularly when vulnerabilities can be leveraged to gain high-level access to systems. The sophisticated use of database features to hide and execute attack tools demonstrates attackers' evolving methods, making it crucial for organizations to elevate their security measures. Addressing such vulnerabilities is essential to protect against unauthorized access, data breaches, and compromised system integrity.

In response, organizations are advised to implement strict input validation, especially for web applications interfacing with databases. Limiting database account privileges and ensuring these accounts cannot perform risky operations like creating Java sources or running unauthorized commands is crucial. Regular security assessments, patch management, and utilizing breach and attack simulation tools can help identify and mitigate vulnerabilities. Enhancing monitoring capabilities can aid in detecting unusual activities early and preventing attackers from fully executing their plans.
