Original Article: https://www.bleepingcomputer.com/news/security/malicious-sites-use-javascript-to-build-malware-in-browser-memory/

1) The article reports on a significant malvertising campaign utilizing fake Solana, Luno, and TradingView webpages to deploy malware using JavaScript directly in browser memory. This method circumvents traditional file downloads, assembling malware incrementally from dispersed components in a process managed by service and shared workers in the browser. Active since late 2024, it targets traders and crypto investors in several countries, focusing on obfuscating its activities by creating unique file hashes for each victim to avoid static detection methods.

2) This campaign highlights a sophisticated evolution in malware delivery that could significantly stress existing detection and prevention strategies. The use of JavaScript and browsers to construct malware in memory makes it difficult to detect, as no complete file is transferred over networks for traditional anti-malware tools to scan. With substantial implications for retail traders and crypto investors, this technique underscores the escalating refinement of cyber threats designed to exploit legitimate pathways and evade security measures.

3) In response, organizations should enhance their endpoint detection and response (EDR) capabilities to catch unusual activities, such as unexpected JavaScript executions and service worker registrations, which might indicate memory-based malware construction. Education programs should inform users about the risks of downloading executables from unofficial sources. Organizations dealing with cryptocurrency and financial trading should implement strict download policies and conduct regular security audits, ensuring only verified and digitally signed files are installed within their systems. Proactively engaging in threat hunting and deploying security technology updates can also increase resilience against these evolving threats.
