Original Article: https://www.bleepingcomputer.com/news/security/jetbrains-warns-of-critical-teamcity-remote-code-execution-flaw/

The critical issue with JetBrains' TeamCity involves an authentication bypass vulnerability, known as CVE-2026-63077, which could allow attackers with HTTPS access to execute remote code and issue system commands. The flaw is significant because it affects all versions of TeamCity On-Premises, while TeamCity Cloud remains unaffected. This vulnerability could compromise sensitive data, configurations, and credentials within CI/CD pipelines, posing serious security risks.

This vulnerability is pertinent as TeamCity is widely used in software development environments. Exploitation could lead to significant disruptions, data breaches, and potentially allow malicious actors to penetrate deeper into systems, affecting various business operations. Additionally, past exploitation of TeamCity flaws by ransomware and state actors underscores the critical need for vulnerability management.

To mitigate risks, users should upgrade to TeamCity 2025.11.7 or 2026.1.3, where the vulnerability is addressed. For those unable to upgrade, JetBrains provides a security patch as a plugin for versions from 2017.1 and above. Implementing additional security layers, such as VPNs for internet-facing servers and ensuring even non-critical interfaces like login pages are secured, can provide extra protection against exploitation attempts.
