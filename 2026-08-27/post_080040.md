Original Article: https://www.bleepingcomputer.com/news/security/hackers-target-microsoft-sharepoint-rce-chain-with-poc-exploit/

**1) What happened:**  
Attackers have targeted a chain of vulnerabilities in Microsoft SharePoint, specifically CVE-2026-55040 and CVE-2026-63520, to execute arbitrary code on unpatched servers. The first vulnerability allows attackers to bypass authentication, while the second enables remote code execution when chained together. Proof-of-concept (PoC) exploits for both vulnerabilities have been published, and attackers have already begun weaponizing these exploits. Despite these vulnerabilities being actively probed, widespread code execution has not yet been observed.

**2) Why it matters:**  
These vulnerabilities pose a significant risk as they can be exploited to gain unauthorized access and control over SharePoint servers, which are often critical components of an organization's IT infrastructure. The fact that proof-of-concept exploits are publicly available increases the likelihood of widespread exploitation by threat actors, potentially leading to data breaches and disruptions. Furthermore, the vulnerabilities may be leveraged in broader attacks, including ransomware, which can result in severe operational and financial impacts.

**3) What actions should be taken:**  
Organizations using Microsoft SharePoint should urgently review and implement security patches and hardening guidelines provided by Microsoft to mitigate these vulnerabilities. They should assess whether any SharePoint servers are unnecessarily exposed to the internet and take steps to limit this exposure. Security teams are encouraged to monitor network traffic for signs of exploitation attempts and utilize detection tools and honeypots like those used by Defused for early identification of potential attacks. Engaging in regular security assessments and employee awareness training will further strengthen defenses against such threats.
