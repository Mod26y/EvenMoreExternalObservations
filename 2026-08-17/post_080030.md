Original Article: https://www.bleepingcomputer.com/news/security/new-amnesiastealer-macos-malware-hijacks-browser-sessions-via-remote-control/

**1) What happened:** A newly discovered malware called AmnesiaStealer is targeting macOS users through ClickFix attacks, allowing attackers to hijack browser sessions via remote control. The malware copies the victim's Chromium profile, facilitating access to authenticated web sessions in a headless browser. It collects data such as passwords, cryptocurrency wallet information, Apple Notes, and other sensitive data from the targeted device. The malware is spread through phishing campaigns using fake GitHub pages, with an infection process that leverages a shell-script loader to download and execute its payload.

**2) Why it matters:** AmnesiaStealer poses a significant threat due to its ability to hijack user sessions and control them in real-time using the Chrome DevTools Protocol (CDP). This gives attackers a high level of access to victims’ online activities, potentially leading to unauthorized access to sensitive accounts, data theft, and financial loss. The emergence of this sophisticated macOS malware highlights the growing threat landscape targeting Apple devices, previously less affected compared to other platforms, and underscores the necessity for robust security measures across all operating systems.

**3) What actions should be taken:** Organizations and users should enhance their cybersecurity posture by implementing robust endpoint protection solutions and educating users about phishing attack vectors to reduce the likelihood of infection. Regular audits and updates of security protocols are advisable, particularly focusing on macOS defenses. Users should be cautious in executing command-line scripts from untrusted sources and employ strong password practices. Updated threat intelligence feeds could help detect campaigns leveraging similar attack patterns. Lastly, cross-comparison of unusual login activities and prompt mitigation can help contain potential breaches quickly.
