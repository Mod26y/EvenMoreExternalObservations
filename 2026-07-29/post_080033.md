Original Article: https://www.bleepingcomputer.com/news/security/vbulletin-fixes-critical-pre-auth-rce-flaw-with-public-exploit/

The article discusses a critical pre-auth remote code execution (RCE) vulnerability identified in vBulletin forum software versions up to 5.7.5 and 6.2.1. This flaw, tracked as CVE-2026-61511, allows attackers to execute arbitrary PHP code due to improper input sanitization in the 'runMaths()' function, which is exploited when processing user-controlled input via the eval() function. A public proof-of-concept exploit is available, increasing the risk of exploitation by bad actors targeting unpatched servers. Despite its decreased popularity, vBulletin still supports many large online communities, making this vulnerability particularly impactful.

The significance of this vulnerability lies in its potential for widespread abuse due to the public availability of an exploit and the continued use of the vBulletin platform by numerous high-traffic communities. The flaw's presence allows for unauthenticated attackers to take control of affected systems, leading to potential data breaches, service disruptions, or further infiltration into network environments. Given past incidents where similar vulnerabilities were exploited, organizations using vBulletin face considerable risk if they are slow to patch this flaw.

To mitigate the risk, organizations operating vBulletin should prioritize updating their systems to version 6.2.2 or applying the available patches for earlier versions deemed 'Patch Level 1.' Security teams should re-evaluate access controls and monitoring for vBulletin servers to detect potentially malicious activity. It would be prudent to conduct security audits focusing on input handling to prevent similar future failures. Increasing awareness of the vulnerability within user communities can also encourage prompt updates and better preparation against exploitation attempts.
