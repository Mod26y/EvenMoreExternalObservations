Original Article: https://www.bleepingcomputer.com/news/security/critical-elementor-pro-bug-exposes-wordpress-sites-to-rce-attacks/

A critical vulnerability, CVE-2026-32475, was discovered in the Elementor Pro WordPress plugin. This flaw allows attackers to upload executable PHP files, enabling remote code execution on the server. The issue arises from a discrepancy in how the plugin’s File Upload module processes empty file entries, permitting malicious uploads to bypass validation. This vulnerability affects versions before 4.2.2 and requires an Elementor form with a File Upload field for exploitation. 

This vulnerability is significant as Elementor Pro is widely used for building sophisticated WordPress websites. With over 10 million active installations, an exploit could potentially impact countless sites, risking unauthorized access and control. It underscores the importance of ensuring that popular web tools are secure given their broad usage in building internet infrastructure. 

To mitigate risk, administrators should upgrade to the latest Elementor Pro version promptly. Additionally, they need to examine the ‘wp-content/uploads/elementor/forms’ directory for malicious files that might have been uploaded during the vulnerability period. Although no active exploitation is reported, regular monitoring and proactive updates are recommended for defense against future vulnerabilities.
