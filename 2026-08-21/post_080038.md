The Cybersecurity and Infrastructure Security Agency (CISA) has issued a warning regarding active exploitation of a critical vulnerability in MLflow, an open-source AI platform. This vulnerability, tracked as CVE-2026-64849, allows unauthenticated attackers to exploit a DNS-rebinding server-side request forgery (SSRF) bug. This security flaw enables attackers to access internal services or cloud metadata configurations on unpatched MLflow instances, potentially allowing them to steal sensitive cloud credentials.

This vulnerability is significant because MLflow is widely used, with over 30 million downloads monthly. The exploitation of this vulnerability can lead to unauthorized access to cloud credentials, which might result in further malicious activity such as data breaches or service disruption in organizations using MLflow. Additionally, CISA's inclusion of this flaw in its KEV catalog highlights the urgency and seriousness of the threat, especially to U.S. government agencies.

Organizations using MLflow should prioritize updating their instances to version 3.15.0 or later to patch the vulnerability. It is advisable to audit and monitor logs for any unauthorized access attempts and review firewall rules to restrict incoming traffic to the MLflow tracking server. Additionally, it is prudent to ensure that only authenticated and authorized users have access to sensitive endpoints and to implement multi-factor authentication wherever possible to enhance security controls.
