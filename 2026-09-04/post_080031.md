**1) What happened:**

Microsoft revealed a bug with the KB5120998 August 2026 preview update for Windows 11 that resets mouse settings on non-English systems. This issue emerges after users install the update, which modifies personalization settings for the mouse cursor without allowing them to restore original settings. The bug is linked to code components specific to non-English installations causing these settings to default automatically. As it’s an optional update, users would need to initiate installation or have settings that apply updates automatically.

**2) Why it matters:**

This bug is significant because it disrupts user experience and workflow, particularly for non-English Windows 11 users who rely on personalized settings for accessibility or productivity. Affected users may face usability challenges, impacting effectiveness in professional and personal use. It highlights gaps in Microsoft's update quality assurance for non-English environments, underscoring the necessity for thorough testing across all language installations. The disturbance caused by the mouse issue, if unresolved, can lead to increased user frustration and potential downgrades or avoidance of updates, affecting system improvements and security.

**3) What actions should be taken:**

Organizations and individual users with non-English Windows systems should be cautious about installing the KB5120998 update. Users who experience the issue may consider temporarily reverting to previous system states if needed. IT departments could monitor Microsoft’s communication for patches or updates addressing this issue. To mitigate potential issues, enabling user education on optional updates and advising only essential updates could be beneficial. Continued dialogue with Microsoft support can also be instrumental in ensuring prompt resolutions and minimizing disruptions to productivity.
