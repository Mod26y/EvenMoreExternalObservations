Original Article: https://www.bleepingcomputer.com/news/security/cisa-windows-task-host-flaw-now-exploited-by-ransomware-gangs/

The article discusses the exploitation of a high-severity vulnerability, CVE-2025-60710, in Windows Task Host by ransomware gangs. This flaw enables local attackers with basic user permissions to escalate privileges to SYSTEM level, gaining complete control of compromised Windows 11 and Windows Server 2025 devices. Although Microsoft has addressed the vulnerability in their November 2025 security update, the Cybersecurity and Infrastructure Security Agency (CISA) recently highlighted its active exploitation, urging prompt remediation to mitigate associated risks.

This matter is critical as it underscores the persistent threat posed by known vulnerabilities, particularly when exploited by ransomware groups. Such privilege escalation flaws allow attackers to bypass standard security measures, achieving substantial control over targeted systems. This vulnerability affects core systems components, making the risks more pervasive and underscoring the necessity for timely patch management in both government and corporate environments.

To address this information, organizations are advised to ensure that their systems are up-to-date with the latest security patches, specifically the one released by Microsoft addressing CVE-2025-60710. Regular vulnerability assessments can identify unpatched systems that may be susceptible to attack. Furthermore, enhancing user authentication protocols and monitoring privileged account usage will reinforce defenses against unauthorized privilege escalation. For systems that cannot be patched, applying vendor-recommended mitigations or considering discontinuation of susceptible products is prudent.
