Original Article: https://www.bleepingcomputer.com/news/microsoft/microsoft-tests-faster-windows-explorer-customizable-context-menu/

1) Microsoft has initiated the testing phase for a faster File Explorer and a redesigned, customizable context menu in Windows 11 preview builds. These changes, aimed at improving speed, performance, and user experience, include tweaks to File Explorer to prevent interruptions during tasks like file renaming, and a streamlined context menu with a "Customize menu" shortcut. Additionally, Microsoft is removing the WMIC tool, a vulnerability exploited by cybercriminals, as part of ongoing efforts to enhance security.

2) These improvements signify Microsoft's commitment to user experience and security. By enhancing File Explorer's speed and reliability and making the context menu customizable, Microsoft addresses consumer feedback and usability challenges. The removal of the WMIC tool is particularly significant for cybersecurity, as it eliminates a potential vulnerability frequently exploited by attackers to execute malicious commands, thereby strengthening Windows 11's defense against cyber threats.

3) Organizations should consider testing these Windows 11 changes in controlled environments to evaluate their impact on workflows and compatibility with existing IT infrastructure. It is beneficial to educate users about the customizable context menu and new features, enhancing productivity. Cybersecurity teams should update risk assessments to account for the removal of the WMIC tool, adjusting any procedures reliant on it. Finally, vigilant monitoring for emerging vulnerabilities and proactive updates will maintain robust security postures.
