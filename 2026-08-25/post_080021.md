Original Article: https://www.bleepingcomputer.com/news/security/hackers-target-wordpress-sites-in-miniorange-auth-bypass-attacks/

Hackers have identified and are actively exploiting two critical vulnerabilities, CVE-2026-61979 and CVE-2026-15981, in the miniOrange SAML 2.0 Single Sign On plugin for WordPress. These vulnerabilities allow attackers to bypass authentication by forging SAML responses, granting them administrative access to sites using the plugin. The exploit leverages a flaw that allows attackers to select and manipulate the signature algorithm to appear legitimate. Although the vulnerabilities were disclosed and patches provided in July, only the free version was initially advised, leaving many paid versions unpatched and vulnerable.

This situation highlights the significance of comprehensive vulnerability disclosure and patch application across all software versions. Failure to notify users of all affected plugin versions potentially left numerous sites vulnerable to exploitation. Considering the high risk of bypassed authentication leading to unauthorized access by malicious actors, organizations using the miniOrange plugin face potential data breaches and loss of control over their sites. The presence of a publicly available proof-of-concept exploit further raises the probability of widespread attacks.

To address these vulnerabilities, organizations using any version of the miniOrange SAML SSO plugin should immediately upgrade to the specified patched versions. It's crucial for administrators to manually verify their plugin versions, as automatic update alerts might not be available for paid versions. Continued monitoring for unusual login activity and employing additional security measures, like two-factor authentication, can mitigate the threats posed by potentially compromised credentials. Additionally, organizations should remain engaged with security advisories to be promptly informed about similar risks in other plugins or systems.
